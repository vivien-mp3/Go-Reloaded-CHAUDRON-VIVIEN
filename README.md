GO RELOADED - CHAUDRON VIVIEN

Bienvenue sur ce projet qui permet de formater les textes correctement

D'abord veuillez vous assurer que vous avez Visual Studio Code ou un éditeur de code quelconque

Download de VS Code : https://code.visualstudio.com

Après télécharger le github en .zip et venez extraire le .zip sur votre ordinateur
OU
Copier le lien github et dans la fichier, sur la barre de chemin, cliquer et entrez " cmd "
puis faites:
git clone <lien du github>

Normalement vous avez mon projet sur votre ordinateur !

Vous pouvez aussi télécharger l'extension "Go" sur les extensions de VS Code

Après tout ça de prêt, vous pouvez écrire la commande suivante sur le terminal de VS Code

go run .\main.go <nom du fichier texte existant> <nom du fichier texte souhaité>

Dans ces deux premiers arguments (qui doivent être mis en guillemets "") Vous devez inscrire des éléments précis.

Le premier:
D'abord vous devez créer un fichier texte avec du texte dedans (évidemment)
Et en anglais plus précisément, vous pourrez écrire un texte souhaitez
Nommez le fichier texte comme vous souhaitez mais l'extension du fichier doit être ".txt"

Le deuxième:
Entrez un nom pour le fichier de texte de résultat. Préferablement avec ".txt" à la fin aussi
Et ce fichier texte sera votre texte formatté !


COMMANDES:

Dans le premier fichier text, vous pourrez écrire des commandes qui permets de formattez le fichier de résultat plus convenablement.

(up) ou (up, <nombre>) permet de mettre chaque mots derrière la commande en majuscule

(low) ou (low, <nombre>) permet de mettre chaque mots derrière la commande en minuscule

(cap) ou (cap, <nombre>) permet de mettre chaque mots derrière la commande avec l'initial en majuscule et le reste en minuscule

(hex) ou (hex, <nombre>) permet de convertir chaque mots derrière la commande en hexadécimal

(bin) ou (bin, <nombre>) permet de convertir chaque mots derrière la commande en binaire
